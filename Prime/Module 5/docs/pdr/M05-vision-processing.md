## 1. Purpose

M05 asserts only that **plate- or vehicle-like objects appear at coordinates in the original frame**. It does **not** read characters, judge HSRP compliance, or make final decisions.

**Lineage invariant (mandatory):**

> `OriginalFrame → DetectionId → RectifiedPlate → OCR/HSRP evidence → Decision`

Downstream evidence must remain joinable to its originating **Talos-owned** `DetectionId`.

## 2. Product context (locked)

| Constraint | Rule |
|------------|------|
| **Remote inference** | Via **M03 only** (`ai_api`); fixture backend for CI |
| **DetectionId** | Generated by Talos; provider IDs are optional provenance |
| **Coordinates** | Canonical **original-frame pixel** boxes after M05 |
| **Empty plates** | Valid success → Continue; not an M05 error |
| **Evidence** | `VisualObservation` only |
| **No semantics** | No plate text, registration fields, HSRP flags, or decisions |

## 3. Scope

### 3.1 In scope

- Stage 1 detect vehicles + plates through M03
- Geometry validation + coordinate normalization
- Score filtering, in-frame overlap suppression, truncation with `DetectionSummary`
- Talos `DetectionId` assignment; vehicle↔plate spatial association
- VisualObservation evidence (`vision.s1`)

### 3.2 Out of scope

| Owner | Capability |
|-------|------------|
| M03 | HTTP clients, retries, cost |
| M04 | Quality (S0), rectify/enhance (S2) |
| M06 | OCR + grammar |
| M07 | HSRP analysis |
| M08 | Final decision / NoPlateDetected implication |
| Stage 6 | Cross-frame pipeline deduplication |

### 3.3 Forbidden outputs

`plate_text`, `registration_number`, `state_code`, `district_code`, HSRP fields (`compliant`, `IND`, `hologram`), final decision outcomes.

## 4. M01 type extensions (normative — build later)

```rust
pub struct DetectionId(pub String); // Talos-owned ULID/UUID

pub struct ProviderRef {
    pub name: String,
    pub model: Option<String>,
}

pub struct Point2d { pub x: f32, pub y: f32 }

/// Canonical original-frame pixel coordinates.
pub struct BoundingBox {
    pub x: u32,
    pub y: u32,
    pub width: u32,
    pub height: u32,
}

pub type ConfidenceScore = f32; // 0.0..=1.0

pub struct PlateDetection {
    pub detection_id: DetectionId,
    pub provider_detection_id: Option<String>,
    pub score: ConfidenceScore,
    pub bbox: BoundingBox,
    pub quad: Option<[Point2d; 4]>,
    pub provider: ProviderRef,
    pub associated_vehicle_id: Option<DetectionId>,
}

pub struct VehicleDetection {
    pub detection_id: DetectionId,
    pub provider_detection_id: Option<String>,
    pub label: String,
    pub score: ConfidenceScore,
    pub bbox: BoundingBox,
    pub provider: ProviderRef,
}

pub struct DetectionSummary {
    pub raw_plate_count: u32,
    pub accepted_plate_count: u32,
    pub filtered_low_score: u32,
    pub suppressed_overlap: u32,
    pub truncated: u32,
    // same counters may exist for vehicles
    pub raw_vehicle_count: u32,
    pub accepted_vehicle_count: u32,
}

pub struct Detections {
    pub vehicles: Vec<VehicleDetection>,
    pub plates: Vec<PlateDetection>,
    pub summary: DetectionSummary,
}
```

**BBox rules:** `width > 0`, `height > 0`, `x + width <= original_width`, `y + height <= original_height`.

## 5. Detection lifecycle (locked)

```text
OriginalFrame
 → M04 Stage 0 (Accept / Degraded)
 → M05 Stage 1
 → Detection Request
 → M03 Capability Router
 → External Vision Provider (or fixture)
 → Raw Provider Detections
 → Geometry Validation
 → Normalize to original-frame pixels
 → Score Filtering
 → Duplicate / Overlap Suppression (in-frame)
 → Talos DetectionId Assignment
 → Vehicle ↔ Plate Association
 → Detections + DetectionSummary
      ├─ 0 plates → Continue → M04 NoPlateDetected
      └─ 1..N plates → M04 Stage 2 (same DetectionId) → M06/M07 → M08
```

---

## 6. Stage 1 behavior

1. Prefer **M02 original frame** bytes (full scene). Do not use plate crops (they do not exist yet).
2. May run when Stage 0 is `Degraded`; skip/halt only if Stage 0 already `Unusable`/`Halt`.
3. Call M03 `detect_vehicles_plates` when `backend = ai_api`; else fixture.
4. Normalize provider geometry to pixel `BoundingBox` (+ optional quad in pixel space).
5. Drop invalid geometry → count toward validation failures / exclude from accepted set.
6. Filter by `min_plate_score` / `min_vehicle_score`.
7. If `[dedup].enabled`, suppress overlapping same-class boxes by IoU ≥ `iou_threshold` (keep higher score).
8. Truncate to `max_plates` / `max_vehicles` by score; increment `truncated`.
9. Assign new Talos `DetectionId` per accepted detection; copy provider id if present.
10. Optionally associate plates to vehicles (containment / IoU assist when `prefer_plates_inside_vehicles`); never drop unassociated valid plates.
11. Write `ctx.detections`; emit VisualObservation evidence `vision.s1`.
12. Always `Continue` on empty accepted plates (state A below).

---

## 7. Empty vs failure

| State | Meaning | Outcome |
|-------|---------|---------|
| A. Success + 0 plates | Valid empty | Continue; empty `plates` |
| B. Malformed geometry / unusable result | Validation | `TalosError::Validation` |
| C. Timeout / unavailable | Infra | `TalosError::Transient` (M03/ADR-0007) |

`0 plates ≠ detection error ≠ provider failure ≠ final rejection`.

---

## 8. Overlap suppression vs Stage 6

| Name | Where | Meaning |
|------|-------|---------|
| Detection suppression | M05 `[dedup]` | Same frame overlapping boxes |
| Pipeline deduplication | M01 Stage 6 | Across frames/files |

Metrics/docs must never mix these terms.
